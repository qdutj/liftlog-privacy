一、这个应用是什么

健身训练记录本是一个在本机运行的训练记录工具：你选择动作，记下每一组的重量与次数，应用保存训练时间、组序和动作历史，并按你设置的秒数做组间倒计时。它不需要注册，也不需要登录；本应用只做记录与算术，不提供训练计划或建议。

二、本机保存什么

你记录的内容只保存在这台设备上，不上传、不同步到开发者或任何第三方服务器。全部保存在本机的应用私有目录内，其他应用读不到：

  • 动作名称：你从预置动作里选的，或你自己新建的动作名。
  • 每一组：动作、重量（以克为单位保存，按你选的单位换算显示）、次数、组序、完成时间。
  • 训练：开始时间与结束时间；以及你创建的训练模板（模板名称与动作顺序）。
  • 你的设置：重量单位、每个动作的组间休息秒数、是否使用大字号、是否同意本政策、是否已解锁完整版、评分邀请的状态。

本应用不读取你的支付记录、账单、短信，也不读取其他应用里的任何数据。重量和次数全部由你手动输入或按步进调整。

四、什么时候联网

你的训练记录不上传、不同步，也不经过任何服务器。本应用只在下面几种情况下联网，都由华为的组件完成，且都在你同意本政策之后：

  • 购买与恢复买断：打开买断页时，由华为应用内支付组件向华为查询一次商品的当前价格；点击购买或恢复购买时，由它拉起华为收银台、查询这个华为账号的购买记录。还没买断时，应用启动时也会向华为查询一次你是否已买过，以便换机或重装后自动恢复。付款过程由华为应用市场完成，本应用接触不到你的支付信息。
  • 联运初始化：每次启动时由华为联运组件完成初始化。这是华为联运服务的接入要求，不含你的训练记录。
  • 检查新版本：每次启动时由华为应用更新组件向华为应用市场查询本应用有没有新版本。

这些请求都不包含你的动作、重量、次数、组序、训练时间或模板。在你同意本政策之前，本应用不会调用上述任何联网功能。若手机上没有安装华为移动服务（HMS Core），启动时不会调用这些功能。

六、你的数据由你支配

  • 导出表格（CSV）：在「我的 → 导出全部记录（CSV）」随时把全部训练记录导出，买不买断都能用，保存位置由你自己选择。
  • 备份到文件：在「我的 → 备份到文件」把全部训练记录、模板、自建动作与训练设置存成一个 JSON 文件，买不买断都能用，保存位置由你自己选择。换机或重装后，用「我的 → 从备份恢复」选回这个文件即可；恢复会替换本机现有的全部记录，且无法撤销。备份文件只在你选择的位置，本应用不会上传它。
  • 删除：在「我的 → 清除全部数据」一次清空全部训练记录、自定义动作和模板。删除和清空无法恢复；完整版状态不受影响。
  • 撤回同意：你可以随时在「我的 → 撤回隐私政策同意」撤回。撤回后本应用立即退出；下次打开时重新询问你是否同意，在你重新同意之前，本应用不会调用第四条所说的联网功能。已记下的训练记录仍保存在本机，如需删除，请先用「清除全部数据」。撤回不影响撤回前基于同意已进行的处理。
  • 保存期限：训练记录一直保存在本机，直到你在应用内删除、清空或卸载本应用。本应用不参与系统云备份；换手机前请先用「备份到文件」或 CSV 自行备份。
